Where to find these on the printer

  • IP address & LAN access code: printer screen → Settings → Network (WLAN). Reserve the IP in your router's DHCP.
  • Serial number: Settings → Device (also on the label at the back).
  • Firmware: Settings → Firmware. The app also reads it from the printer once connected.
  • Network mode: whether "LAN Only" and "Developer Mode" are on. On Authorization-Control firmware, third-party temperature commands are rejected unless Developer Mode is enabled.

The access code is encrypted in the database with a key stored in /etc/bambu-filament-controller/controller.env. It is never shown again after saving.
